# Samyama Comptes

App instal·lable (PWA) per portar les finances d'autònom de Samyama:
moviments, models 303, 130, 111 i 115, calendari fiscal i previsió d'any.

## Publicar a GitHub Pages

1. Crea un repositori nou a GitHub (per exemple `comptes`).
2. Puja-hi tot el contingut d'aquesta carpeta (index.html, sw.js, manifest.webmanifest i la carpeta icons).
3. Settings → Pages → Branch `main`, carpeta `/ (root)` → Save.
4. Obre `https://lluis75.github.io/comptes/` al mòbil amb Chrome → menú ⋮ → «Instal·lar l'aplicació».

Les dades es guarden només al mòbil. Fes còpies des d'Ajustos → «Desar còpia».
Càlculs orientatius: verifica-ho sempre amb el teu assessor fiscal.
